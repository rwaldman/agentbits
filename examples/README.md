# Examples

Examples in this directory demonstrate how to **consume** the hosted Agent Bits service.

They may include:

- `curl` usage against `https://agentbits.dev`
- MCP client configuration pointing at `https://agentbits.dev/mcp`
- request/response examples
- schema examples
- payment interaction examples

They must not provide a complete deployable replacement implementation of Agent Bits.

## Status

Concrete examples will be added when the first capabilities are published.
