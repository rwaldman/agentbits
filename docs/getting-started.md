# Getting started

Agent Bits is a hosted service of small, reliable utilities and datasets for AI agents.

## 1. Identify the service

- Website: https://agentbits.dev
- MCP: https://agentbits.dev/mcp
- API: https://agentbits.dev/api

## 2. Discover capabilities

Start with:

- [`../llms.txt`](../llms.txt)
- [`../catalog.json`](../catalog.json)
- [`discovery.md`](./discovery.md)

## 3. Invoke

Use MCP for tool-oriented clients, or HTTP for direct JSON requests.

## 4. Handle results and errors

Responses are JSON and schema-defined. Errors use stable machine-readable codes.

## Current status

No capabilities are published yet. This documentation surface is scaffolding for the initial public contract.
