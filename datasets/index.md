# Datasets

Canonical dataset pages for Agent Bits.

- [countries](/datasets/countries) — Versioned curated country metadata dataset used by country_lookup and countries_bulk.
- [currencies](/datasets/currencies) — Curated currencies dataset (v1, 20 records) used by related lookup tools.
- [languages](/datasets/languages) — Curated languages dataset (v1, 20 records) used by related lookup tools.
- [mime-types](/datasets/mime-types) — Curated mime-types dataset (v1, 20 records) used by related lookup tools.
- [timezones](/datasets/timezones) — Curated timezones dataset (v1, 17 records) used by related lookup tools.
