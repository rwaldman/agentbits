# Look up TLD metadata

Resolve a DNS top-level domain to curated classification and usage metadata.

This intent maps to the canonical capability `tld_lookup`.

## Canonical page

https://agentbits.dev/tools/tld-lookup

## MCP

`tld_lookup`

## HTTP

`GET https://agentbits.dev/v1/tlds/{tld}`
