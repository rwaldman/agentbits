# Look up currency from ISO 4217 code

Resolve an ISO 4217 currency code to name, symbol, decimals, and related countries.

This intent maps to the canonical capability `currency_lookup`.

## Canonical page

https://agentbits.dev/tools/currency-lookup

## MCP

`currency_lookup`

## HTTP

`GET https://agentbits.dev/v1/currencies/{code}`
