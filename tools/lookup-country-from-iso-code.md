# Look up country from ISO code

Resolve an ISO 3166-1 alpha-2 country code to name, currency, calling code, languages, and region metadata.

This intent maps to the canonical capability `country_lookup`.

## Canonical page

https://agentbits.dev/tools/country-lookup

## MCP

`country_lookup`

## HTTP

`GET https://agentbits.dev/v1/countries/{code}`
